# C4-модель

В данном разделе представлены архитектурные диаграммы, выполненные по модели.

Диаграммы используются для визуального описания архитектуры системы, ее границ, взаимодействия с пользователями и внешними сервисами, а также взаимосвязей между основными компонентами.

## Диаграммы

| Уровень | Описание | Диаграмма |
|---------|----------|-----------|
| C1 — Context Diagram | Контекстная диаграмма, показывающая взаимодействие «Органайзера домашних дел» с пользователем и сервисами экосистемы Wildberries. | [PNG](c1.png) |
|C2 — Container Diagram | Диаграмма контейнеров, показывающая внутреннюю структуру органайзера, основные сервисы, базы данных и взаимодействие между ними. | [PNG](c2.png) |
